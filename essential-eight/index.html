What the Essential Eight covers

The Australian Signals Directorate (ASD) publishes eight mitigation strategies that stop most common cyber attacks. Its maturity model sets out three levels for each one. This self-check covers Maturity Level One, the baseline that protects a business from opportunistic attackers using widely available tools.

  1. 01

    Patch applications

    Attackers go after known flaws in common software. Most of those flaws already have a fix. Your job is to install it before someone uses it against you.

  2. 02

    Patch operating systems

    Windows, macOS and the firmware on your network gear need the same treatment. An old operating system is one of the easiest ways in.

  3. 03

    Multi-factor authentication

    A stolen password on its own shouldn't be enough to get into your email or bank. MFA asks for a second proof, such as a code from your phone.

  4. 04

    Restrict administrative privileges

    Admin accounts can change anything. If an attacker gets one, they own the network. Keep these accounts few and use them only for admin work.

  5. 05

    Application control

    Most malware arrives as a file that someone runs from their Downloads folder. Application control lets only approved programs run from the places users can save files.

  6. 06

    Configure Microsoft Office macros

    Macros are small programs inside Word and Excel files. Attackers hide malware in them and email the file. Most staff never need macros.

  7. 07

    User application hardening

    Web browsers are your staff's front door to the internet. A few settings close off common tricks, such as malicious ads.

  8. 08

    Regular backups

    If ransomware hits or a laptop dies, backups decide whether you lose a day or the business. A backup only counts once you've restored from it.

Who this is for

Australian small businesses running Microsoft 365 or Google Workspace who want to know where they stand before paying for an assessment. Most of the fixes are settings you already have access to, and the self-check points you to where each one lives.

ASD recommends getting all eight strategies to the same level before aiming higher, so the results put the quickest, highest-impact fixes first.
